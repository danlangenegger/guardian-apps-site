security@guardianapps.ch

When reporting a problem

Please include:

  • your Jira Cloud site name
  • the affected Jira project key
  • a short description of the problem
  • the steps required to reproduce it
  • any visible error message

Please do not send passwords, authentication tokens or confidential Jira issue content.

Support scope

We provide support for:

  • installation and licensing questions
  • configuration problems
  • unexpected backlog check results
  • application errors
  • compatibility issues with supported Jira Cloud environments

Response time

We aim to respond to support requests within 2 business days.
