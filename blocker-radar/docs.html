Blocker Radar for Jira

Documentation

Installation, blocker detection, filtering, prioritization and troubleshooting for Blocker Radar.

Last updated: October 2026

Blocker Radar for Jira gives teams a focused, cross-project view of active delivery blockers in Jira Cloud.

1. Overview

Blocker Radar identifies Jira issues that use an "is blocked by" issue-link relationship and brings active blocker relationships together in one view.

The App currently provides:

  • A cross-project view of active blockers
  • Priority-based ordering
  • Project filtering
  • Status filtering
  • Summary metrics for active blocker relationships
  • Direct links to blocked and blocking Jira issues

2. Installation

Blocker Radar is installed from the Atlassian Marketplace into a Jira Cloud site.

To install the App:

  1. Open the Blocker Radar Marketplace listing.
  2. Select the option to install or start a trial.
  3. Select the Jira Cloud site where the App should be installed.
  4. Approve the requested Jira permissions.
  5. Open Blocker Radar from Jira after installation completes.

Blocker Radar is a Jira Cloud app built on Atlassian Forge.

3. What counts as an active blocker?

Blocker Radar uses Jira issue links to identify blocking relationships.

An issue is considered actively blocked when:

  • the issue contains an "is blocked by" relationship to another Jira issue
  • the blocked issue is not in Jira's Done status category
  • the blocking issue is not in Jira's Done status category

Relationships involving completed blocked issues or completed blockers are excluded from the active blocker view.

4. Blocker overview

The top of Blocker Radar provides summary information about the currently displayed blocker relationships.

The current summary includes:

  • Active blocker relationships
  • Highest-priority relationships
  • High-priority relationships
  • Number of affected Jira projects

Summary values automatically update when filters are applied.

5. Priority ordering

Blocker Radar orders blocker relationships according to the priority of the blocked Jira issue.

The default priority order is:

  1. Highest
  2. High
  3. Medium
  4. Low
  5. Lowest

Other or custom priority values may appear after the standard priorities.

6. Filtering blockers

Blocker Radar provides filters to help narrow the active blocker list.

Project filter

Select a Jira project to display blocker relationships associated with that project.

Status filter

Select a Jira issue status to display only blocked issues currently in that status.

Filters can be cleared to return to the complete active blocker view.

7. Understanding a blocker relationship

Each Blocker Radar entry displays information about the blocked Jira issue and the issue preventing it from progressing.

The blocked issue section includes:

  • Issue key
  • Summary
  • Status
  • Priority
  • Project
  • Assignee

The Blocked by section includes:

  • Blocking issue key
  • Blocking issue summary
  • Blocking issue status

8. Opening Jira issues

Jira issue keys displayed in Blocker Radar are clickable.

You can open both the blocked issue and the blocking issue directly in Jira for investigation and follow-up.

9. Permissions

Blocker Radar uses read-only Jira access to retrieve issue information and issue-link relationships.

The current version does not require Jira write permissions and does not modify Jira issues.

10. Data and hosting

Blocker Radar is built on Atlassian Forge and runs on Atlassian-hosted infrastructure.

The current version does not require an external application server or external database for its core functionality.

Jira issue information is retrieved when Blocker Radar is used. The current version does not maintain its own persistent database of Jira issues or blocker relationships.

11. Troubleshooting

No blockers are displayed

Confirm that your Jira issues use the "is blocked by" issue-link relationship and that both the blocked issue and blocker are still active.

An expected blocker is missing

Check whether either issue has moved into Jira's Done status category. Completed relationships are intentionally excluded from the active blocker view.

Also confirm that the Jira issue link uses the expected blocking relationship.

A blocker relationship looks incorrect

Open the affected Jira issues and verify the configured issue-link relationship and current Jira statuses.

Filters return no results

Clear the Project and Status filters to return to the full active blocker list.

12. Support

If you need help with installation, blocker detection or unexpected results, visit the Blocker Radar Support page.
